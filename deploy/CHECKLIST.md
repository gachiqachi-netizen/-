# 运行 setup.sh 前的网页清单

只改代码时 Docker 构建的依赖层走缓存；改了依赖清单才会重新安装依赖。

- [ ] 腾讯云控制台 → ICP 备案：API 域名备案已完成（菜单以实际后台为准）。
- [ ] 腾讯云控制台 → 云服务器 CVM → 安全组 → 入站规则：业务端口只开放 80、443；8800 不对公网开放。运维登录端口仅对受信任地址开放。
- [ ] 腾讯云控制台 → DNSPod / 域名解析 → 解析记录：API 域名的 A 记录指向 CVM 公网 IP。
- [ ] 腾讯云控制台 → SSL 证书 → 我的证书：证书已申请、签发并下载 Nginx 格式。
- [ ] 用安全传输方式把 Nginx 证书和私钥上传到服务器 `/etc/nginx/certs/`；把商户私钥 pem 和微信支付公钥 pem 上传到服务器受限的临时目录。脚本会询问四个文件的绝对路径，把支付 pem 复制到 `deploy/secrets/`。不要放进 Git 提交或公开目录。
- [ ] 微信商户平台 → 产品中心 → AppID 账号管理：商户号已关联小程序（菜单以实际后台为准）。
- [ ] 手边准备：API 域名、商户号、32 位 APIv3 密钥、商户证书序列号、微信支付公钥 ID、小程序 AppID 和 AppSecret；分别从微信商户平台的商户信息/API 安全及微信公众平台的小程序开发设置取得。

完成后在仓库根目录执行 `sudo bash deploy/setup.sh`。敏感输入不会回显。
