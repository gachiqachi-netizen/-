# 00 用户与风格方向（改版的前提，先于 01–05）

> 这份文件推翻了 03 里“素纸朱砂”的方向。01–05 的信息架构和任务拆分大部分还能用，但视觉部分（03、04、tokens.wxss、mockups.html）要按这里的结论重做。
> 结论来自对产品、知识库和现有代码的判断，**还没有用户数据验证**；文末列了花一两天就能做的验证办法。

## 1. 谁在用“自己串”

### 主要人群：18–32 岁的年轻女性，买水晶为主

- **买的是心情，不是材料**：选粉晶、紫水晶、草莓晶，是因为“好看”“像我”“今年想要点好运气”，图的是情绪价值和一点仪式感。她们不关心“8mm、¥3.50”，关心的是戴上去好不好看、拍出来好不好看、寓意说得动不动人。
- **审美来源是小红书和首饰品牌**：通透、干净、柔和，大面积留白，图片说话；不喜欢中式符号堆砌，也不喜欢大红大金。
- **“自己串”是表达，也是送礼**：送闺蜜、情侣款、生日月份石、考试季。分享出去的那张图，比下单页还重要。
- **耐心很短**：第一次进来，30 秒内要看到一条“好看到想要”的手串，2 分钟内要串出一条自己的。

### 次要人群：文玩、菩提、木珠的用户（男性居多、年龄偏大）

- 知识库里木、菩提、香料一共 60 种，比水晶（16 种）多，这批用户不能丢。
- 但他们在意的是料子和做工，不在意界面装饰。界面只要干净、把珠子的质感拍清楚，他们就能接受。**为他们做“中式风”，反而会把主要人群赶走。**

### 所以：界面为年轻女性设计，“珠子本身”服务所有人

界面退后、做得克制，把舞台让给珠子：水晶的通透、木头的纹理、菩提的肌理。人群之间的差别交给内容（款式、文案、排序）去做，不交给界面风格。

## 2. 现在为什么显得老套、廉价

| 现象 | 出处 | 给用户的感觉 |
|---|---|---|
| 热门款名字是“好运连连”“金榜题名”“岁岁平安”“步步高升” | `server/seed.py` | 像节日祝福短信、像长辈的群发，年轻人不会想戴 |
| 品牌红 #c8302e 用在按钮、选中态、价格、安全提示上 | `app.wxss`、各页 wxss | 像促销页；真正要醒目的安全提示反而不醒目 |
| 106 种颜色、20 种字号、15 种圆角、17 种阴影 | 全部 wxss 统计 | 像逛超市，每块都在喊，没有主次 |
| 卡片套卡片、处处描边、处处标签 | 首页、编辑器、订单 | 像网页后台，不像一个 App |
| 珠子画成平涂色块 | 编辑器、缩略图、示意稿 | 产品卖的就是珠子，珠子不好看，整个产品就廉价 |
| 编辑器第一屏堆满尺寸、价格、分类、筛选 | `pages/editor` | 像在填采购单，不像在做手作 |

Fable 的“素纸朱砂”方向解决了“乱”，没解决“老”：宣纸色、朱砂红、宋体标题，指向的是文玩和中式礼品店，正好是主要人群最不想要的感觉。它的规范也还是太多：60 个颜色变量、24 类组件、9 种按钮修饰。

## 3. 克制预算（硬约束，两个方向都适用）

整个小程序只允许用下面这些。超出预算要在汇报里说明理由。

| 项目 | 预算 | 说明 |
|---|---|---|
| 颜色 | **9 个** | 中性色 5 级（页面底、卡面、分隔、次要字、主字）+ 强调色 1 个 + 警示红 1 个 + 成功色 1 个 + 遮罩 1 个。珠子和照片负责色彩，界面不负责 |
| 字号 | **4 档** | 大标题、标题、正文、辅助字；价格只用正文或标题字号加粗，不单独造字号 |
| 字重 | **2 档** | 常规、加粗 |
| 圆角 | **2 档** | 面板/图片一档、胶囊一档 |
| 阴影 | **最多 1 种** | 只给浮在内容上的底部操作栏或弹层 |
| 描边 | **0** | 靠留白和底色分组，不画框 |
| 间距 | **3 档** | 紧、常规、段落 |
| 按钮 | **2 种 + 文字链接** | 主按钮（每屏最多 1 个）、次按钮；只有一个高度，列表内用小号 |
| 提示 | **1 个组件、2 种语气** | 普通（中性灰底）、安全/错误（警示红）；不出现黄条、蓝条、绿条 |
| 表单 | **用列表格式** | 标签在左、输入在右，一行一项，跟微信支付、设置页一样；不自己设计输入框样式 |
| 步骤条 | **不用** | 流程短，靠页面标题和底部按钮文案说明“下一步做什么” |
| 状态标签 | **只用文字颜色** | 不用彩色胶囊底 |
| 图标 | 线性一套，同一粗细 | 不用 emoji、不用字符图标 |

判断标准：随便截一屏，数得出的颜色不超过 4 种（不算珠子和照片），按钮不超过 2 种。

## 4. 两个可选方向

两个方向都遵守上面的预算，差别在“舞台”怎么搭。对比稿见 `directions.html`。

### A 透光（推荐）

- 页面底是带一点冷调的雾白，卡面纯白；主按钮用近黑的墨色，强调色只用一点雾紫，表示选中。
- 珠子做出通透感：高光、折射、半透明的暗部。托盘是浅灰的雾面台子，像首饰店的展示台。
- 文案轻、短、有情绪：“今天想戴点温柔的”“给考试加点底气”。
- 优点：干净、高级、跟微信本身的白色界面不打架；照片和珠子最出彩；年轻用户熟悉这种首饰品牌和种草笔记的观感。
- 风险：做不好会显得空，所以珠子的渲染和图片必须先到位。

### B 丝绒首饰盒

- 托盘、手串详情的大图区用深色丝绒（深墨绿或夜蓝），水晶在深底上会“发光”；其余页面仍然是白底。
- 强调色用浅香槟金，只用在细线和选中态。
- 优点：一眼就有轻奢感，水晶、南红、蜜蜡这类亮色料子特别出彩。
- 风险：深色区不能太多，否则像夜店或赌场；黑檀、紫檀这类深色木珠放在深底上会看不清，需要给托盘留浅色选项。

### 不推荐

- 中式宣纸、朱砂红、宋体：指向文玩和礼品店，主要人群会觉得老气。
- 粉色少女风、贴纸手帐风：太窄，男性和送礼场景会排斥，而且很快就过时。

## 5. 珠子的质感是第一优先级

界面做得再好，珠子还是平涂的圆点，产品照样廉价。建议分三步：

1. **先做 40 种主力珠子的实拍抠图**（水晶类和热门款用到的珠子优先），每种一张正面透明底 PNG，统一光线。托盘、缩略图、分享图都用它。这一步需要负责人安排拍摄或采购图片。
2. 其余珠子先用程序生成的“仿真球”过渡：有高光、有暗部、半透明的料子带一点透光，不再是平涂色块。
3. 3D 只留在试戴里；编辑器托盘用 2D 实拍图，又快又真。

主包有 2MB 上限，图片放到服务器或对象存储，按需下载并缓存，不进包。

## 6. 文案也要换腔调

- 热门款改名：从“祝福语”改成“场景 + 心情”，例如“月光白”“初恋粉”“考前定心”“周一不慌”。具体名单交给运营定，`server/seed.py` 只是示例数据。
- 寓意讲成一句话的小故事，不堆吉祥话；仍然只讲寓意不讲功效，过 banned 词表。

## 7. 需要负责人拍板

1. **主要人群**：是否确认“18–32 岁、买水晶为主的年轻女性”。如果主攻文玩用户，方向要整体换。
2. **方向**：A 透光（推荐）还是 B 丝绒首饰盒。
3. **珠子实拍**：能不能先拍或采购 40 种主力珠子的透明底图片。
4. **热门款改名**：是否同意换掉现在的祝福语式名字。

## 8. 一两天内能做的验证

- 在小红书搜“水晶手串 DIY”“自己串手链”，看点赞最高的 30 篇笔记的配色、拍法、标题，跟 A、B 两个方向对照。
- 把 `directions.html` 里两个方向的首页截图发给 5–10 个目标用户，问“哪个你更想点进去”“哪个更像会送朋友的”。
- 找 3 个同类小程序，各截首页和编辑页，看它们哪里显得廉价，避开同样的问题。
