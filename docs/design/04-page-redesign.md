## 1. 首页 `pages/home/home`（稿 01–03）

**布局**
1. 上身图：贴边，高 600rpx。运营配置的封面；没有就用第一条热门款的圆环。
2. 大标题（56rpx）。
3. 输入条。
4. 心情快捷词：一排小号次按钮，最多 4 个，一行放不下的不显示。
5. 文字链接：自己串。
6. （往下滑）列表行：接着串上次那条（本机有草稿才显示）、拍照做同款。
7. 标题“大家在串”。
8. 款式格，两列贴边。

**组件**：输入条、按钮（小号次按钮）、列表行、款式格、手串图、状态占位。

**文案**

| 位置 | 文案 |
|---|---|
| 大标题 | 今天，想串一条 / 什么样的？ |
| 输入条占位 | 说一句心愿，比如“想要清冷一点” |
| 快捷词（运营可配，示例） | 清冷一点、去去班味、考前定心、送闺蜜 |
| 自己串入口 | 或者，从一颗珠子开始自己串 |
| 继续 | 接着串上次那条 ·「名字」· N 颗 |
| 拍照 | 拍一张照片，做同款 |
| 区块标题 | 大家在串 |
| 款式格 | 名字 / ¥128 |

**交互**：点发送键或快捷词，带着这句话切到 AI 配并直接发送；点款式格进手串详情。

**状态**
- 加载：上身图和快捷词的位置是骨架块；标题、输入条、自己串入口照常可用（稿 03）。
- 目录失败且没有离线快照：“大家在串”下面是错误态“款式没加载出来”和“再试一次”；上半屏照常可用。
- 用的是离线快照：标题“大家在串”右边一行辅助字“离线数据，联网后更新”。
- 没有款式：整个“大家在串”区块不显示。

**不再有**：轮播、四个圆形入口、卡片上的“试戴”“用这款”按钮、促销文案（“首单立减”要从数据里删，见 05 的 B8）。

## 3. 编辑器 `pages/editor/editor`（稿 06–09）

**布局**
1. 舞台：白底，高 580rpx，手串居中。右上角三个图标：撤销、叠戴预览、更多。
2. 尺寸行：左边“18 颗 · 152mm”，右边“手围 15cm · 合适”（点右边去手围页）。
3. 1rpx 分隔线。
4. 文字分段（材料分类），右边筛选图标。
5. 选珠格：5 列，纵向滚动。每格是珠子、名字、一行“8mm · ¥6”。
6. 底部操作栏：一个通栏主按钮，文字里带价格。

**组件**：手串图、文字分段、珠子、底部操作栏、按钮、弹层、提示。

**文案**

| 位置 | 文案 |
|---|---|
| 导航栏标题 | 手串名字；没起名时“新的一条” |
| 空托盘（舞台中间） | 点下面的珠子，开始串 |
| 尺寸行右侧 | 手围 15cm · 合适 ／ 手围 15cm · 还差约 12mm ／ 手围 15cm · 超出约 9mm ／ 多圈串，长度以实际佩戴为准 |
| 没量过手围 | 先按 15cm · 合适（其余同上） |
| 补齐（尺寸行下方的文字链接，偏短时才有） | 用「海蓝宝 8mm」补齐 3 颗 |
| 选中一颗时的尺寸行 | 第 5 颗 ｜ 前移 后移 删除 好了 |
| 分类 | 水晶、玉石、木、菩提、配件（照目录的分类） |
| 主按钮 | 串好了 · ¥128 |
| 少于 6 颗 | 主按钮禁用；按钮上方辅助字“至少 6 颗才能串成一条” |
| 叠戴预览说明 | 叠戴预览 · 上下两条是你的作品 |
| 叠戴预览没有作品时 | 叠戴预览 · 上下两条是示意 |
| 有材料下架 | 「紫檀 8mm」已下架，点它换一颗（警示红，放在尺寸行的位置） |

- 尺寸文字全部用主字色；偏短、超出时这几个字加粗。尺寸规则不改：总长目标 = 手围×10 + max(8, 2.5×主珠直径 − 5) mm，差值在 −4 到 +6mm 算合适，54 颗及以上按多圈处理。文字来自现有的 `logic.stats()`。
- 有安全提示的珠子（朱砂、元宝菩提等）：格子右上角一个 16rpx 的红点。

**弹层**（都用同一个弹层组件）

| 弹层 | 怎么打开 | 内容 |
|---|---|---|
| 珠子详情（稿 09） | 长按选珠格 | 名字和尺寸、大图、一句寓意、“¥6 / 颗 · 规格”、材料安全提示（有才显示）、主按钮“加一颗” |
| 筛选 | 筛选图标 | 尺寸、色系、寓意三组，每组是文字分段（选中的加粗）；主按钮“看 N 种珠子”，文字链接“清除筛选” |
| 更多 | 更多图标 | 列表行：改名字、按颗数串、按手围重排、材料清单、穿绳（弹力线／编织绳 +¥5）、音效 |
| 材料清单 | “更多”里 | 每种一行（珠子、名字、数量、小计），有安全提示的下面跟提示 |

**状态**
- 空托盘：舞台中间一行次要字。
- 选中一颗（稿 08）：那颗放大，其余变淡；尺寸行换成四个文字动作；此时点选珠格是替换这一颗。
- 叠戴预览（稿 07）：再点一次图标关闭。
- 目录加载中：选珠格是骨架块，主按钮禁用。
- 目录失败：选珠格的位置是错误态加“再试一次”；托盘里已有的珠子照常显示。
- 筛选没结果：“没有符合的珠子”加文字链接“清除筛选”。
- 3D 不可用：沿用现有的平面圆环。

**不再有**：两个“设置”弹层、齿轮图标、手围的三处入口、材料面板左侧的分类栏、常驻的材料清单入口、“分享设计”按钮。
