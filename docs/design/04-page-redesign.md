# 04 逐页改版稿

> 配套的高保真示意：[mockups.html](mockups.html)（浏览器直接打开；跟随系统浅色 / 深色）。下面每页标的“稿 NN”是 mockups.html 里手机屏左上角的编号。
> 组件名和类名见 [03](03-design-system.md)；流程见 [02](02-core-flows.md)。
> 稿子里的手串、照片、手是示意图形。真实页面里托盘中是 `bracelet3d` 或 `bracelet-thumb` 的渲染结果。

每页的写法：**布局**（从上到下）→ **组件** → **文案** → **状态** → **和现状的差异**。

所有页面共用的三条：

- 页面底色 `--c-bg`，左右边距 32rpx，区块间距 24rpx（卡片之间）或 48rpx（大区块之间）。
- “正在使用离线示例数据”统一用 `<ui-notice tone="warn" full icon="wifi-off" text="正在使用离线示例数据，价格以联网后为准"/>`，放在页面最顶部。各页 wxml 里现有的那段内联样式全部删掉。
- 页面 wxss 里不出现颜色、字号、圆角的字面量。

**布局**
