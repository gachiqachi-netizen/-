# 08 工作台、操作反馈、AI 配、品牌标识

> 负责人 2026-11-12 看完 mockups-v3 的意见：工作台的核心是“选珠子好用”，现在手串占的地方太大，选珠区挤，用户也不知道自己选了哪些；每一步操作都要给反馈，正反馈和负反馈都要；设计一个 logo（暂名“珠养养”），放进托盘中间的空白；AI 配要支持语音和拍照，对话气泡要重做，推荐内容要完整、准确，不能为了放而放。
> 本文替代 07 第 3.1 节（工作台）和 3.2 节（AI 配）的具体做法。画稿见 `mockups-v4.html`。

## 1. 工作台：重点是选珠子

### 1.1 三个问题

1. 为什么来：挑珠子，串成一条。
2. 第一眼看到：**可以挑的珠子**，和**已经挑了什么**。手串是结果预览，不是主角。
3. 下一步：点一颗珠子加上去。

### 1.2 屏幕怎么分

| 区域 | 占屏 | 内容 |
|---|---|---|
| 托盘 | 约 1/3 | 手串正视图，中间是品牌标识；右侧三个图标（撤销、叠戴、分享） |
| 状态行 | 一行 | 颗数 · 长度 · 合不合适，旁边一条小量尺 |
| 已选 | 一行 | 每种珠子一个小标签：珠子图 + 名字 + ×数量，可以横向滑；点一个标签，托盘里这种珠子全部高亮，并出现“全部去掉”“换成别的” |
| 选珠区 | 约一半 | 分类文字标签 + 四列珠子格；格子里是珠子图、名字、“8mm ¥6”；已经用了的珠子，右上角是数量角标 |
| 底部栏 | 一行 | 价格 + “串好了” |

托盘可以上拉放大（看细节、拖动排序），放大时选珠区收起；松手回到默认比例。

### 1.3 珠子数和长度的规则（不能改）

长度 = 所有珠子直径相加；目标 = 手围 × 10 + max(8, 2.5 × 主珠直径 − 5)；差值在 −4 到 +6mm 算合适。
例：手围 15cm、8mm 主珠，目标 165mm，合适区间 161–171mm，要 21 颗（168mm）。20 颗是 160mm，还差约 5mm；22 颗是 176mm，超出约 11mm。**之前所有稿子里“18 颗 · 152mm · 合适”是错的，已改正。**

## 2. 每一步操作都要有反馈

原则：用户做了一件事，界面要在同一瞬间告诉他“发生了什么”和“现在怎么样”。成功要让人有一点愉悦；出问题要说清楚原因和怎么办，不能只是“点了没反应”。

| 操作 | 视觉 | 触感/声音 | 文字 |
|---|---|---|---|
| 点珠子加上去 | 珠子从格子飞进托盘落位；格子角标数字 +1；状态行长度跳动更新 | 轻震动（`wx.vibrateShort` light）+ 现有的落珠声（静音时不响） | 托盘底部冒一个小提示“+1 海蓝宝”，1 秒消失 |
| 加到刚好合适 | 量尺游标进入合适区间时，状态行文字变成“刚好合适” | 中等震动一次 | “刚好合适，可以串好了” |
| 加多了（超出） | 游标出界；状态行变成“超出约 11mm” | 无 | 状态行下出现一行“去掉 1 颗刚好 [去掉最后一颗]”；不拦截继续加 |
| 不够长时点“串好了” | 按钮不禁用，点了以后量尺抖一下 | 短震动 | “还差约 5mm，再加 1 颗就合适” |
| 点托盘里的一颗 | 这颗放大、其余变淡；底部换成“左移 / 右移 / 换一颗 / 删除” | 轻震动 | — |
| 删除 | 珠子缩小消失，旁边的珠子合拢 | 无 | “已删除 1 颗月光石 [撤销]”，3 秒 |
| 撤销 | 珠子回到原位 | 轻震动 | “已撤销” |
| 第一次加有安全提示的珠子（朱砂等） | 先弹底部弹层讲清楚，点“知道了，继续加”才加上 | 无 | 弹层内容来自知识库 `safety.note` 和 `care` |
| 点缺货的珠子 | 格子轻微左右晃 | 短震动 | “这颗暂时缺货，看看相似的 [月光石]” |
| 达到 54 颗 | 状态行变成“多圈串” | 无 | “已经是多圈串了，长度以实际佩戴为准” |
| 保存作品 | “我的作品”图标上出现小圆点 | 无 | “已存到我的作品” |
| 网络失败 | 按钮恢复可点 | 无 | 具体原因 + “再试一次” |

文字提示统一用一个“浮动提示”组件：黑底白字胶囊，出现在托盘底部中央，不遮挡选珠区；带操作的（撤销、去掉）右侧放一个文字按钮。

## 3. AI 配

### 3.1 三种输入，一个输入条

输入区照成熟的 AI 对话应用（如 Claude）的做法：一个大圆角框，**上面一整行是输入框**（提示语一行放得下，最多自动长到 5 行）；**下面一排小按钮放在框内**：左边“+”（拍照、相册）和当前条件标签（如“手围 15cm”，点了改），右边语音，输入框里有字时变成黑色的发送箭头。打字的地方永远是整行宽。

- **语音**：和微信一样“按住说话”，按住时出现音量波形和“松开发送，上滑取消”；识别出的文字先显示在气泡里，用户能看到自己说了什么（反馈），识别错了可以点气泡改。需要录音授权和语音识别服务（**需后端/第三方**），没有识别服务前先隐藏语音按钮。
- **拍照**：可以拍或从相册选一张图：喜欢的手串、穿搭、某种颜色氛围。AI 回复里先说它从图里看到了什么（“看到的颜色：浅蓝、米白；感觉：清冷”），再给推荐。和“拍照做同款”区别：做同款是尽量还原原图的珠子，这里是按照片的感觉配一条新的。
- **文字**：输入框提示“说说想要的感觉、送谁、预算”。

### 3.2 对话样式

- 用户的话：右侧，浅灰底（卡面色）、主字色，大圆角，靠近右边的那个角小一点；不用黑底。
- AI 的回复是**一条消息**：两三句话说清按什么配、为什么，下面一张**推荐卡片**（图、名字、价格、颗数和长度、用了哪几种珠子、“改一改”“去下单”），再下面一行“另外两种”的小标签；快捷改法贴在输入区上方。**完整的理由、材料清单、注意事项不放在对话里**，点卡片进手串详情页（09 第 29 条）。
- 第一次进来：一行说明加三个示例，示例只放“一句话 → 配出的手串名”，点一下就用这句话发送。

### 3.3 推荐内容写什么（每一项都要有依据；第 1、6、8 项在对话里，其余在点开后的手串详情页）

| 顺序 | 内容 | 依据 | 例 |
|---|---|---|---|
| 1 | **我理解的是**：把用户的话拆成几个条件 | 用户输入 | 清冷 · 通勤 · ≤¥100 · 手围 15cm（点“手围”可改） |
| 2 | 手串大图、名字、价格、颗数、长度、是否合适 | 计价和尺寸规则 | 白月光 ¥92 · 21 颗 · 168mm · 合适 |
| 3 | **为什么这样配**：颜色、每种材料的寓意、尺寸，三段，每段一两句 | 知识库 `meaning.text`；尺寸规则 | 见 3.4 |
| 4 | **材料清单**：每种珠子的数量、单价、小计，加起来等于总价 | 目录价格（整数分） | 月光石 8mm ×7 ¥56 … |
| 5 | **戴的时候注意**：只列这条手串真正涉及的 | 知识库 `care`、`safety` | 月光石怕磕碰，避免和硬物撞击 |
| 6 | **想调整**：三到四个改法，点了重新配 | 用户条件的相邻方向 | 更清冷一点 · 换 6mm 更秀气 · 预算再低一点 · 加一点粉 |
| 7 | 操作 | — | 主按钮“去下单”；次按钮“放到工作台改”；文字链接“戴上看看” |
| 8 | **另外两条**：同样条件下的其他配法，小图 + 名字 + 价格 + 一句差别 | — | “月光石换成海蓝宝为主，更偏蓝” |

规则：
- 寓意只用知识库里的说法，讲寓意不讲功效，过 banned 词表。
- 数字（价格、长度、颗数）全部由前端按规则算，不让模型自己写数字。
- 不满足用户条件时要直说：例如预算 100 以内配不出月光石为主的，就写“月光石为主的要 ¥130 左右，这条用白水晶为主，控制在 ¥92”。
- 识别不了或配不出来：说清原因，给两个可以直接点的改法，不只说“出错了”。

### 3.4 “为什么这样配”的示例（白月光）

- **颜色**：月白和一点浅蓝，都是低饱和的冷色，和通勤常穿的黑、白、灰、蓝都搭，不抢眼，符合“清冷”。
- **材料**：月光石转动时有一层光晕，像月光，常用来寓意温柔、浪漫；白水晶古人叫“水精”，比喻纯净、明澈，用来铺底、控制预算；两颗海蓝宝颜色像海水，寓意清澈、宽广，点在两侧提一点蓝。
- **尺寸**：8mm 是通勤最不显眼又不小气的大小；按手围 15cm，21 颗总长 168mm，戴上留一指左右的余量。

## 4. 品牌标识（暂名“珠养养”）

- 名字：负责人提的暂名。正式名字先查商标和小程序名称（**负责人**）。
- **走字标路线，不用图形。** 圆点环像加载图标，“一珠一线”“两颗珠”也偏可爱、偏小程序，都作废。首饰品牌的高级感几乎都来自字：国际大牌是纯字标，东方高端品牌是“精致中文字 + 一行衬线英文”。
- **已定（2026-11-12，负责人）：方案一 宋体中文 + 衬线拼音。** 下面保留三个方案的记录：
  - **一 宋体中文 + 衬线拼音（推荐）**：“珠养养”用精致的宋体、拉开字距，下面一行衬线大写“ZHU YANG YANG”。宋体只用在标识上，界面不用。
  - 二 拉丁字标为主：衬线大写拉丁名作主标识，中文退到第二行；拉丁名需要另起。
  - 三 细无衬线、大字距：和白盒界面最统一，最克制。
- 托盘中央用分隔色的字标；分享海报导出时保留。
- 标识最终做成图片（SVG），不依赖用户手机上的字体。字体要确认商用授权；正式稿请品牌设计师精修。
