# 14 后台账号和权限（2026-11-12）

> 负责人：后台要有基础的权限配置，谁能看、谁看得到什么。进货先不做。
> 稿子：[mockups-admin.html](mockups-admin.html) A01（登录改为账号 + 密码）、A18–A20。

## 1. 现在的问题

| 现在 | 后果 |
|---|---|
| 后台只有一个共用口令（`ADMIN_TOKEN`），谁登录都一样 | 做单师傅也能改价、退款、看所有客户的手机号和地址 |
| 所有操作都记成 `admin`，操作记录里只有 IP | 出了问题查不到是谁做的 |
| 质检人是手填的名字 | 谁都可以写别人的名字 |
| 登录状态存在服务进程内存里 | 服务一重启所有人都要重新登录；以后多台服务器时会登录不上 |

## 2. 做法

**每人一个账号，账号属于一个角色，角色决定能用哪些功能、能看到哪些敏感信息。**后端每个接口都按权限检查；前端把没有权限的菜单和按钮藏起来，只是为了好用，不是安全措施。

### 2.1 账号

- 账号名 + 名字（操作记录里显示名字）+ 角色 + 状态（在用 / 停用）。
- 密码至少 8 位，只存加盐哈希（用标准库的 `hashlib.scrypt`），不存明文。
- 负责人新建账号时设一个临时密码；**第一次登录必须改密码**。负责人可以重置别人的密码，重置后也要先改密码。
- 连续输错 5 次锁 10 分钟（沿用现在的规则）；登录 8 小时有效。
- **停用账号立刻生效**：这个人已经登录的会话马上失效。
- 至少要有一个在用的负责人账号；系统不允许停用或降级最后一个负责人。
- 原来的 `ADMIN_TOKEN` 只用来**创建第一个负责人账号**：服务启动时如果一个账号都没有，就用它登录，进来后只能做“创建负责人账号”这一件事。有了账号以后，这个口令不能再登录。
- 登录会话存进数据库，不再放在进程内存里。
- 以后可以加“企业微信扫码登录”，现在不做。

### 2.2 权限点（一共 21 个）

| 分组 | 权限点 | 说明 |

| 订单 | 看订单 | 订单列表和详情 |
| | 处理订单 | 开始制作、发货、改物流状态、改运单号 |
| | 改地址和备注 | 改收货地址、写内部备注 |
| | 取消订单 | 要二次确认 |
| 售后 | 处理售后 | 同意、拒绝、确认收到退货、补寄 |
| | 退款 | 确认退款（钱的出口，单独一个权限） |
| 内容 | 审核评价 | 通过、驳回、下架 |
| | 编辑首页和文章 | 首页配置、文章 |
| | 编辑和发布条款 | 条款、用户协议、隐私政策 |
| 商品 | 编辑商品 | 新建、改资料、上下架、关联知识库 |

| 用户 | 查用户 | 按手机号后 4 位或订单号找人 |
| 敏感信息 | 看完整手机号和地址 | 没有这个权限时，后端只返回打码后的（138****8000、浙江省杭州市西湖区***） |
| | 看成本价和毛利 | 没有时后端不返回成本字段 |

“今天”页、知识库（查看）所有人都能看；“今天”页只显示这个人有权限处理的事。

几条理由：
- **做单师傅看不到客户的手机号和地址**：做单只需要珠序、用料、手围和客户备注。工单页本来就不显示这些。
- **退款、改价格、发布条款只给负责人**：都是直接影响钱和对外承诺的操作。人多了以后，负责人可以给某个客服单独开“退款”。
- **运营看订单但看不到全号**：运营要看卖得怎样，不需要联系客户。

负责人可以改这四个角色的权限，也可以新建角色（比如“兼职客服”）。“负责人”这个角色不能改、不能删。

### 2.4 数据范围（只有一条）

做单师傅可以设成“只看分给我的工单”或“看全部工单”，默认全部（人少的时候互相顶班）。其他角色都是看全部，前期不做按店铺、按地区之类的数据隔离。

### 2.5 没有权限时

- 菜单里不出现没权限的页面。
- 页面里不出现没权限的按钮（不是变灰，是不出现）。
- 直接打开没权限的地址：显示“你没有这个页面的权限，找负责人开通”，下面写负责人的名字。
- 后端拒绝时返回 403 和一句原因，前端原样显示。

### 2.6 操作记录

- 每一条都记**账号名字**（不再是 `admin`）、时间、IP、操作、对象、改了什么。
- 权限相关的操作也记：新建账号、改角色、改权限、停用、重置密码。
- 只有“管理账号和权限”的人能看全部操作记录；其他人只能在订单、工单详情里看到和这一单有关的记录。

## 3. 和已有设计的关系

- 12 第 3 节第 6 条“列表里手机号只显示后 4 位，详情里才显示全号”改为：**没有“看完整手机号和地址”权限的人，详情里也只看到打码的**；有权限的人在详情里点“显示全号”才显示，并记一条操作记录。
- 工单页的质检人不再手填，自动记成当前账号（A04、A05 的“质检人”变成只读）。
- 订单详情的“记录”区、操作记录页（A14）的操作人一列，显示账号名字。

## 4. 库存和进货

**现在不做进货。**后端的库存是四档状态（有货 / 快没了 / 缺货 / 预售），不是数字。前期运营在商品编辑里手动标，用户端缺货的珠子变淡、不能加（工作台已经这样设计）。

- 后台稿里原来画的“剩 6 颗”“库存 320”和“珠子快卖完 3 种”按数字算的写法，已改成四档状态（A02、A10、A11）。
- 等哪天需要按数量管库存（比如月单量几百、珠子种类上百、常常缺货才发现），再做进货：供应商、采购单、入库（数量、批次、进价）、下单自动扣减、盘点。到那时“快没了”才由数量自动算出来，成本价也从进价来。
