## 这次定下来的事

1. **视觉**：纸色底 `#f5f1ea`，卡片不描边不投影，托盘用暖色绒布渐变；朱砂 `#b73a2b` 只用于主按钮、选中、tab 选中；价格用墨色 DIN 数字；**红色文字全站只留给安全提示和错误**。T13 的五个问题都有结论（03 第 1.2 节）。
2. **规矩**：颜色 30 个变量、字号 7 档、间距 8 档、圆角 5 档；50 个线性图标 + 4 个 tab 图标，全站不用 emoji 和字符图标。
3. **tab**：保留 4 个。首页（逛）/ 自己串（工作台：起点 + 我的作品）/ AI 配 / 我的（账号、订单）。
4. **手串详情页**：原“设计完成”页（路由不变）。热门款、AI 方案、我的作品、编辑器“完成”都先到这里，再“改一改”或“去下单”。
5. **不拦路**：浏览和设计不强制量手围（默认 15cm 并明说），只在“去下单”时强制确认一次；登录静默进行，失败才出登录页。
6. **编辑器**：尺寸量尺常驻；两个“设置”弹层合并；有安全提示的珠子在格子上就有红色角标。
7. **下单**：收货信息提到最上面；安全提示独立成条并要勾选；改价和提交确认用自绘弹层；支付说明常驻；提交后如实停在“待支付”，没有任何“成功”图形，没有“去支付”。
8. **订单**：状态头 + 五步进度，不再展示内部的五组状态码；新增订单列表页（按状态筛选）；售后先走“联系客服”。
9. **页面数**：16 个不变（删跳板页 `pages/ar-tryon`，加 `features/orders`）。

## 这套方案没做什么

- 没改任何小程序代码和后端代码，只有 `docs/design/` 下的文档。
- 没在微信开发者工具里验证过任何东西。`mockups.html` 只在浏览器里看过（宽屏、375 宽、深色各看过一遍）。
- 图标的 `data:` SVG 落地方式（03 第 4.3 节）需要真机确认，文档里给了退回方案。
