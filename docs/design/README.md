## 已定事项

1. **方向**：全站白盒，首页也是。叠戴只留两个功能：首页的心情快捷词、编辑器的叠戴预览，都按白盒的样子做。实验室方向只保留 AR 试戴入口。“素纸朱砂”和 A/B 对比稿作废。
2. **预算**（00 第 3 节）：颜色 8 个（预算 9，成功色没用）、字号 4 档（56 / 34 / 28 / 24 rpx）、字重 2 档、圆角 2 档（直角和圆形）、阴影 1 种、描边 0、间距 3 档、按钮 2 种加文字链接、提示 1 个组件 2 种语气、组件 12 个、变量 26 个。第一期不做深色模式。
3. **红色只留给材料安全提示和错误**。有安全提示的材料在选珠格（红点）、珠子详情、材料清单、手串详情、确认订单、分享落地页都看得到。
4. **tab**：4 个。首页 / 自己串（工作台和我的作品）/ AI 配 / 我的。
5. **首页**：一张上身图、一句话、心愿输入条、心情快捷词、自己串入口，往下是“大家在串”。没有轮播和促销。
6. **手串详情页**：所有手串共用（原“设计完成”页）。热门款、AI 方案、我的作品、编辑器“串好了”都先到这里。
7. **手围不拦路**：默认 15cm 并明说，只在“去下单”时确认一次。
8. **无感登录**：删掉登录页，启动时静默登录，全站不出现“登录”二字（06 第 2 节）。
9. **订单**：一个主状态、一句说明、一行四步进度、最多一个主按钮；物流常驻；独立的“我的订单”页和“申请售后”页（06 第 3 节）。
10. **下单**：收货信息在最上面；安全提示要勾选；改价和提交确认用弹层；没有真实支付，提交后如实停在“待支付”，没有“去支付”和对勾。
11. **不动的规则**：尺寸规则（总长 = 手围×10 + max(8, 2.5×主珠直径 − 5) mm，合适区间 −4 到 +6mm，54 颗及以上按念珠）、金额按分的整数、订单状态契约、下单幂等和价格复核。
12. **页面数**：16 个。删 `pages/login`、`pages/ar-tryon`，加 `features/orders`、`features/after-sale`。

## 这套方案没做什么

- 没改任何小程序代码和后端代码，只有 `docs/design/` 下的文档。
- **没在微信开发者工具里验证过任何东西。** `mockups.html` 只在浏览器里看过（宽屏和 375 宽各一遍）。
- 稿子里的照片位置是灰色块，珠子是程序画的过渡效果；换成实拍图后的观感没有验证。
- 本地 SVG 图标在真机上的显示（D2）、实拍图缓存的真机表现（D5）需要真机确认。
- 结论没有用户数据验证，00 第 8 节列了一两天能做的验证办法。
