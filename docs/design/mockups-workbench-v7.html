1. 珠子大小的规则

规则说明
实物比例 s₀手机逻辑像素 1px ≈ 0.16mm（iPhone 163 点/英寸），即 1mm ≈ 6.3px。小程序拿不到屏幕物理尺寸，按这个通用值算，不同手机误差约 ±10%。
托盘可用直径 AA = min(屏宽 − 2×20, 托盘高 − 50 − 2)；50 是名字和按钮那一行加 8px 间隔，手串不碰按钮。图标改到右上横排后不再占两侧宽度；375 宽的手机 A = min(335, 252) = 252px。
手串需要的直径（mm）d = 目标长度 ÷ π + 最大珠径。目标长度按规范 1.3（手围 15cm、8mm 主珠 → 165mm），所以 d = 165 ÷ π + 8 ≈ 60.5mm。用目标长度而不是当前长度，加珠子时比例不变（U35 的固定圈）。
比例尺 ss = min(s₀, A ÷ d)。能放下就按实物大小；放不下才缩小。上例 s = 252 ÷ 60.5 ≈ 4.17px/mm，即 约 0.7 倍实物，量尺下方左侧小字写“约 0.7 倍实物大小”。
珠子图尺寸只有托盘里的手串按 s 画（8mm → 33px，10mm → 42px）。选珠格里的珠子一律同样大小 40px（“已选”列表里 32px），不按 mm 缩放，避免大小悬殊看着乱；尺寸靠格子下方“8mm ¥6”的数字区分（2026-11-20 负责人定）。
看实物大小托盘上拉放大（08 规范 1.2 已有）时 s = min(s₀, 屏宽 ÷ d)，375 宽手机约 0.98 倍，接近实物。

2. 珠子种类多时怎么选

方案结论
顶部一排分类标签横滑（现在）超过 4–5 个就要横滑，后面的看不见、不知道还有什么；和下面的珠子格上下滑方向冲突。不用。
左侧竖排分类栏（本稿）电商分类页的熟悉做法（09 第 13 条）；分类再多也是上下滑；右边珠子格独立上下滑。分类顺序：已选、全部、水晶、玉石、木质、菩提、金属配件……按后台分类自动生成。

3. 已选怎么放

方案结论
单独一行横滑胶囊（现在）种类多了要横滑才看全，还占一行高度。不用。
分类栏第一项“已选 N”（本稿，对方也这么做）点开右侧换成列表行：珠子图、名字、规格单价，右侧圆形加减键夹着数量，减到 0 去掉该种（可撤销）；点托盘里的珠子，仍然高亮同种并出现“左移/右移/换一颗/删除”。

4. 返回

按微信导航栏规范：返回图标在导航栏最左、和右侧胶囊垂直居中对齐，标题居中，只有图标不写字。tab 页的微信自带导航栏不能加返回，所以工作台要用自定义导航栏（只这一页），高度、标题字号和自带的一样；tools/check-ui.py 里“不能用 custom”的规则给工作台单独开例外并写明原因。

一屏一种对齐名字、状态行、底部栏左边距 20；分类栏 84 宽贴左；手串圈在托盘水平居中
同一信息只出现一次已选数量只在分类栏“已选 N”和格子角标；长度只在状态行

量尺沿用现有 .meter：4px 胶囊线；灰色段 = 合适区间（按规范 1.3 计算），黑色段 = 当前长度，超出变红；不画刻度竖线；“合适”小字在色段正下方
