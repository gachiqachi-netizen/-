- 完成页固定操作栏：原生button默认宽度挤占价格区。明确两按钮宽度，价格区可伸缩，避免文字逐字换行。

## 后续修改优先级（未在本轮擅自重排产品）
1. P1 订单点击应进入只读订单详情；再购作为独立次要按钮，避免误创建另一笔。
2. P1 编辑器把材料选择提升到核心操作区：预览与材料区同屏；名称/寓意和高级工具收起；保留一键铺满。
3. P1 尺寸异常下单需明确确认单圈/多圈及实际尺寸；不能只显示15cm而忽略33cm串长。
4. P1 开发版目录强制走离线数据，即使服务在线也不刷新：后台改珠子无法可靠反映到开发版，需拆开离线演示与真实联调模式。
5. P2 完成页让保存、试戴、下单清楚分层；AI评价是可选动作，不占据主流程必经位置。
6. P2 我的作品统一列表，云同步做状态而不是第二套列表；明确最新版本和冲突。
7. P2 分享页减少两阶段准备操作，明确失败和重试；保留真实发送由用户确认。
8. P2 删除/停用尚不可兑现的首单优惠宣传。
