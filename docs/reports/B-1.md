新增/改动的接口（方法 路径 登录 返回）：
- POST /api/my/uploads — user — 收 {filename, contentType, data(base64)} → {"id","url"}；格式/大小/超限 400
- POST /api/wechat/media-check — public（微信消息签名 sha1 校验，dev 未配令牌放行）— 微信回调 JSON（result.trace_id/suggest）→ {"ok","id","checkStatus"}；签名失败 400，记录不存在 404
- GET /uploads/user/<日期>/<名> — 公开但受限：checkStatus 非 passed 时仅上传者（Bearer 会话）和后台（admin Cookie）可见，其余一律 404（与“记录不存在/文件不存在”同一个 404）；带合法且没过期的 e/k（HMAC，1 小时）时不看 checkStatus，k 不对或过期照旧按权限判断；扩展名只认 jpg/jpeg/png/webp；未过审图片加 Cache-Control: private, no-store；realpath 防目录穿越
- 环境变量：PUBLIC_BASE_URL（送审取图完整地址前缀，未配时开发环境 fail-open 放行、正式环境报错）；MEDIA_LINK_SECRET（k 的 HMAC 密钥，未配时开发环境用 dev-only 占位、正式环境报错）

不涉及金额；uploads 表无尺寸规则相关内容。
