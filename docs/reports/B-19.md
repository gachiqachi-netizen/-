| 卡上的验收项 | 结果 | 证据 |

| 无知识库数据时回退到文件 | 通过 | `test_kb_store.py::test_missing_database_data_falls_back_to_files` |
| 知识库表为空时，89 颗珠子的目录请求最多检查一次 `stamp` | 通过 | `test_kb_store.py::test_empty_kb_table_checks_stamp_once_for_catalog` |
| 返回内容不变 | 通过 | 同一临时 SQLite 库和同一 HTTP 接口，两次响应均 40929 字节，SHA256 前 16 位均为 `7221ef8122c5831c` |

本机 `GET /api/catalog`（HTTP 200）：`KB_STAMP_TTL=0` 模拟旧行为，0.852 秒、`stamp` 936 次；默认 5 秒，0.009 秒、`stamp` 1 次。线上耗时需服务器更新后由负责人复测。缓存读写用锁串行化，避免保存和请求并发时重新缓存旧值。

审核补测：清空临时 SQLite 的 `kb_items`，让知识库回退到文件，再请求同一接口。`KB_STAMP_TTL=0` 时 0.180 秒、`stamp` 936 次；默认 5 秒时 0.008 秒、`stamp` 1 次。两次均为 HTTP 200、40929 字节，SHA256 前 16 位均为 `7221ef8122c5831c`。TTL 到期后，仍按原顺序查 `stamp` 和文件 mtime。
