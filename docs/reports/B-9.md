## 6. 没做 / 没验证 / 偏离卡片
- "confidence < 0.6 显示可能不准"的阈值判断在前端（C5c），本卡只负责把 confidence 给到前端。
- 置信度是模型按 prompt 自报（schema 约束 0–1），不是 provider 级 logprobs——三个 provider 的 JSON schema 模式都给不了字段级概率；已按"给不出就 None"处理，没有编数字。如果负责人要求 provider 级置信度，需要换支持 logprobs 的调用方式，另开卡评估。
- 行为变化（卡片允许的旧行为去除）：`ok=true` 但 main 不在料包时，旧行为抛 `RuntimeError` 走 502（前端本地兜底）；新行为返回 200 + `{ok:false, reason:"unknown_beads"}`，前端同样走本地兜底，用户无感。
