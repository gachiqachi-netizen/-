# H7 交流素材导入

## 改动

- `tools/import_hc_materials.py`：`prepare` 在 Mac 上处理原图并生成 `import.csv`；`import` 在服务器容器内读取该文件，预览时不写数据库或 `UPLOADS_DIR`，`--apply` 才复制图片并调用 `import_beads.import_rows` 入库。服务器步骤没有 Pillow 依赖。
- `server/tests/test_import_hc_materials.py`：自造 CSV 和图片验证两步流程、无 Pillow 导入、金属关键词、绳子跳过、图片裁切、价格、文案、预览及重复导入。
- `H7-assets/`：六张合成对比图。仓库内没有真实素材。

CSV 的“简介”“详情”直接丢弃。重量没有对应的现有商品字段，故未导入。知识库未匹配时，名称含“银、金、镀、镶钻、吊坠、吊牌、跑环、花托、光珠、铃铛、十字架”判为 `metal`；含“绳”的行优先跳过并单列。其余无法确认材质的行列入“材质待确认”，不导入。图片无法处理的行不导入；处理后仍完全不透明的图片列入“图片有问题”，供负责人后台换图。

## 图片存储

后台将商品图片直接写在 `UPLOADS_DIR`（默认 `DATA_DIR/uploads`），公开地址为 `/uploads/<文件名>`。`prepare` 生成以原图内容哈希命名的 `hc-*.png`；`import --apply` 将需要的新商品图片复制到后台的 `UPLOADS_DIR`，数据库保存对应 `/uploads/` 地址。原图不修改。预览不创建或写入 `UPLOADS_DIR`。

## 负责人执行命令

Mac 上，在项目根目录执行（把两个路径换成实际绝对路径）：

```bash
python3 -m pip install -r tools/requirements-dev.txt
python3 tools/import_hc_materials.py prepare /path/to/hc-release/assets/materials_export --output-dir /path/to/hc-prepared
```

将整个 `/path/to/hc-prepared` 目录传到服务器。服务器容器内，进入部署后的项目根目录，沿用后台现有数据库与 `UPLOADS_DIR` 环境配置（把准备目录路径换成容器内实际绝对路径）：

```bash
python3 tools/import_hc_materials.py import /path/to/hc-prepared
# 检查预览报告后，再执行写入：
python3 tools/import_hc_materials.py import /path/to/hc-prepared --apply
```
