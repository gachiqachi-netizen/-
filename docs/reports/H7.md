# H7 交流素材导入

## 改动

- `tools/import_hc_materials.py`：读取 `materials_summary.csv`，按名称匹配知识库，将匹配到的类别转换成已有材质字段，处理图片后调用 `import_beads.import_rows`。默认只预览；`--apply` 写库。同名同尺寸同材质沿用已有去重逻辑。
- `tools/tests/test_import_hc_materials.py`：用自造的 3 行 CSV、3 张小图验证预览、写入、去重、价格、文案和图片处理。
- 本报告与 `H7-assets/`：六张合成对比图。仓库内没有真实素材。

CSV 的“简介”“详情”被直接丢弃。重量没有对应的现有商品字段，故未导入。无法匹配知识库或无法确定材质的行列入“材质待确认”，不会入库。图片无法处理的行也不会入库；处理后仍完全不透明的图片列入“图片有问题”，供负责人后台换图。

## 图片存储

后台将商品图片直接写在 `UPLOADS_DIR`（默认 `DATA_DIR/uploads`），公开地址为 `/uploads/<文件名>`。脚本要求 `--output-dir` 与该目录相同，生成以原图内容哈希命名的 `hc-*.png`，数据库保存对应的 `/uploads/` 地址。原图不修改。预览会生成处理后的图片，但不写数据库。

## 负责人在服务器运行

在任务卡合并、代码部署完成并解压素材后，把下面的两个路径换成服务器上的实际绝对路径。`UPLOADS_DIR` 应为后台当前使用的图片目录，`DATABASE_URL` 使用后台现有环境配置。

```bash
cd /path/to/deployed/project
export UPLOADS_DIR=/path/to/existing/server/uploads
python3 tools/import_hc_materials.py /path/to/hc-release/assets/materials_export --output-dir "$UPLOADS_DIR"
# 检查预览报告后，再执行写入：
python3 tools/import_hc_materials.py /path/to/hc-release/assets/materials_export --output-dir "$UPLOADS_DIR" --apply
```
