# TRY-2 我的手执行报告

## 实现

- 新增手腕拍照引导，支持从相册选择单张照片；引导提示手背朝上、斜 45°。
- 照片在本机离屏画布读取，通过 TRY-1 的模型配置、下载和缓存机制进行一次识别。识别结束立即释放 tracker。0/5/17 号关键点推算椭圆；手围换算采用 `手围 ÷ π × 1.15` 的经验估值。
- 低置信度或没有检测到手时使用引导框默认位置，并提示拖动。单指移动，双指缩放及旋转；支持重拍。
- 无抠图模式隐藏手腕宽度带内的后半圈珠子，保留两侧、前半圈和阴影。照片只在本机处理，没有上传路径。
- 试戴页现在默认进入“我的手”的拍照入口；真实模特手照片尚未到位，因此模特手入口先隐藏，相关代码保留。
