# 第一波验证清单（在微信开发者工具里操作）

每一项照着做，看到“应该看到”的结果就打勾；不一样的地方截图记下来，发给 Claude。

## 准备（约 10 分钟）

在装了微信开发者工具的那台 Mac 上，打开终端，进入项目文件夹：

1. 切到合并分支并拉最新代码：
   ```bash
   git fetch origin
   git checkout codex/wave1-integration
   git pull
   ```
   （也可以让 Codex 帮你做这一步：“切到 codex/wave1-integration 并拉最新代码”。）
2. 如果 `tools/hand-tracker/models/handpose/v1/` 不存在，先下载模型：
   ```bash
   python3 tools/hand-tracker/download_models.py
   ```
3. 启动本地后端（这个终端窗口一直开着）：
   ```bash
   PORT=8801 ADMIN_TOKEN=local-dev-only DISABLE_DEMO_ORDERS=1 DEV_LOGIN=1 python3 server/app.py
   ```
4. 打开微信开发者工具 → 导入项目 → 目录选项目里的 `miniprogram` 文件夹。
5. 右上角 **详情 → 本地设置**，勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**。
6. 点 **编译**，首页能看到热门款和珠子，就说明连上了。
7. 另开一个浏览器窗口打开后台 `http://127.0.0.1:8801/admin`，口令填 `local-dev-only`（后面改价要用）。

## 验证项

### T1 环境地址
- [ ] 首页正常显示热门款、珠子目录。
- [ ] 详情 → 基本信息里能看到当前是开发版；控制台没有“环境配置失败”的红字。

### T3 材料清单和安全提示
- [ ] 进入“自己串”，选几颗珠子，再加 1 颗**朱砂**或**元宝菩提**（没有就在后台上架一颗，品种选朱砂）。
- [ ] 编辑页价格上方有“材料清单”入口，入口上有红字提示；点开能看到每种珠子的数量、小计、卖点、一句讲解，有毒的那颗有红字说明。
- [ ] 点“完成设计”→ 去下单：材料清单同样有红字提示。
- [ ] 填测试收货信息（随便写，手机号用 13800000000）点提交：弹出一个确认框（尺寸不合适时标题是“请确认制作尺寸与材料安全”，否则是“请确认材料安全提示”）；点**返回修改**，订单没有生成，页面出现红字提示。
- [ ] 再点提交：不再弹窗，直接生成“待支付”订单；进订单详情，材料和红字提示都在。

### T16 下单前刷新价格
- [ ] 进入下单页前，记下某颗珠子的单价。
- [ ] 到后台把这颗珠子改价（比如 5 改成 8），保存。
- [ ] 回到小程序重新进入下单页：弹出“材料信息已更新”，列出“¥5.00 → ¥8.00”。
- [ ] 点“暂不确认”：提交按钮是灰的，切换编织绳或礼盒后**仍然是灰的**。
- [ ] 重新进入并点“确认新价格”：总价按新价格算，可以提交。
- [ ] 在终端按 Ctrl+C 停掉后端，回到首页刷新：页面顶部出现“正在使用离线示例数据”；进下单页**不能提交**。验证完重新启动后端。

### T4 缩略图
- [ ] “我的”页、AI 配、首页的手串缩略图都正常显示，没有黑块、没有串图。
- [ ] 有条件的话多存几条作品（10 条以上），在“我的”页快速上下滑，不卡、不黑块。

### T2 AR 试戴
开发者工具对相机支持有限，这一项最好用真机（见下一节）。在工具里至少验证：
- [ ] 进入 AR 试戴页，能看到 0–100% 的模型下载进度。
- [ ] 第二次进入，进度很快到 100%（读的是缓存）。
- [ ] 在终端停掉后端再进 AR 页：约 20 秒后提示失败，有“改用照片试戴”按钮，点了能进照片试戴页。

## 真机（可选，建议做）

1. 复制 `miniprogram/config.local.example.js` 为 `miniprogram/config.local.js`，把里面的地址改成这台电脑的局域网地址（系统设置 → 网络里查，例如 `http://192.168.x.x:8801`）。
2. 手机和电脑连同一个 Wi‑Fi，开发者工具点 **预览**，用微信扫码。
3. 在手机上重点看：AR 试戴首次下载耗时和能否跟住手、红字安全提示的显示和滚动、缩略图。
