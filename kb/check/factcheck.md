| mila 蜜蜡 | "规范里蜜蜡属于琥珀"在宝石学上成立，但 GB/T 16552-2017 对"蜜蜡"能不能单独作为定名、怎么写，本次没取得原文条款。 |
| yueguang-shi 月光石 | "彩月光多为白色拉长石"是宝石学界共识（GIA 等），但本次检索名额有限，没有为它取出处。 |
| shanhu（CITES 附录 III 现状） | 中国 2008 年列入附录 III 的 4 种红珊瑚，CIBJO 资料说有过到期和延续（https://cibjo.org/wp-content/uploads/2024/10/CIBJO-INFORMATION-SHEET-Background-about-coral-for-educators.pdf ），现在是否仍在附录 III 没核实。国家一级这一点已经确认。 |
| shiliu 石榴石 | "酒红色的多是镁铝榴石"存疑。按经验，市售酒红色石榴石串珠多为**铁铝榴石**或镁铝-铁铝过渡种，但没取得出处。 |
| qingjin 青金石 | 叫法"金精石"存疑。中药里的"金精石"一般指蛭石类矿物，用它当青金石的别名可能有误，没取得出处。 |
| afuhan-yu（"雅安玉"） | "雅安玉"的矿物组成没核实，不确定能不能直接归为"大理石"。 |
| tansang 坦桑石 | 规范名应写"坦桑石"还是"黝帘石"，没在 16552 原文里核实到。 |
| dongling-yu 东陵玉 | 现行标准里"东陵石"能否作为定名、规范名写"石英岩玉"还是"石英岩"，原文没核实到。 |

未证实：**12 条**（其中 shanhu 的 CITES 部分和 afuhan-yu 的雅安玉部分是条目内的子项）。

## 4. 大类分法意见（共 8 条）

注：淘宝、京东、小红书的类目页面本次没有逐一抓取，以下按这几个平台通行的手串、散珠导购结构（"水晶/天然石""琥珀蜜蜡""珍珠""翡翠/和田玉""文玩：菩提、木质、核雕、沉香""藏式/多宝"）来判断，属于经验意见。

1. **hecheng（合成与再造）不应作为品种**。它是"处理/人工属性"，应该做成全库通用的标记字段（合成、再造、拼合、染色、充填）。再造琥珀并回 hupo，再造绿松石并回 lvsong，合成水晶并回对应的水晶条目，在属性里标出。
2. **chenxiang、tanxiang 从 wood 移出，和 incense 合并成"沉香·檀香·香珠"大类**。沉香在淘宝、京东都是独立的一级导购入口，用户是按"香"来逛的。这样沉香木珠和沉香粉珠（chenxiang-fen）也能放在同一处对比，方便讲清两者的区别。崖柏（yabai）也以香味为卖点，可以在这个大类里交叉引用。
3. **ganlan（橄榄核）从 bodhi 移到新的"核雕"子类**，或者挂在 wood 下。平台上它属于文玩"核雕"，主要卖雕工，和菩提子"盘玩变色"的逻辑不一样。椰壳（yeke）可以留在 bodhi。
4. **mila 不要和 hupo 平级分开，改成"琥珀蜜蜡"一个入口**。平台类目一般就叫"琥珀/蜜蜡"，用户也是一起逛的。蜜蜡放在琥珀下面做细分（透明度：透明琥珀/半蜜/蜜蜡），名称上也更符合规范。
5. **gem 大类有 24 个品种，太杂，建议拆成两个**：
   - "彩色宝石"：bixi、shiliu、hailanbao、tuopa、tansang、jinqing、linhui、zilihui。偏刻面、偏珠宝，按颜色和净度买。
   - "天然石·矿物"：ying-shi、putao-shi、hongwen、lalima、shujulai、tianqing、fangna、chitie、huoshan、kongque、heiyao。这些在小红书上通常和水晶店的货一起卖。

   另外可以考虑把 crystal 改名为"水晶与天然石"，把"天然石·矿物"并进去。
6. **lvsong（绿松石）、qingjin（青金石）建议单独列，或者归进"藏式/多宝"**。绿松石在平台上和南红、蜜蜡同属"文玩/藏式"的主力品类，价格和盘玩逻辑都更接近玉石。放在"其他宝石与矿物"里会被埋没。tianzhu、gu-zhu 也可以挂"藏式/多宝"标签做交叉入口。
7. **chitie 的"合成磁石"移到 manmade**。所谓"磁石"多为人造磁性材料，不是赤铁矿。chitie 只留天然赤铁矿，和"玻璃不是水晶"的处理方式保持一致。
8. **banned 大类之外，增加一个"限售/需来源证明"标记**，挂在 shanhu（红珊瑚科国家一级）、cheqv（砗磲科一级/二级）、xiaoye-zitan、huanghuali、suanzhi、daye-zitan、ziguang-tan、chenxiang、jinsinan、lvtan、xue-tan 上。这些不是一律禁售，但小程序需要提示"仅收合法来源货"，AI 推荐时也要降权。红珊瑚是国家一级保护动物，尤其不建议和普通"有机宝石"一样正常推荐。
