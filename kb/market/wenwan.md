**卖点词要点（南红）**
- 标题骨架几乎都是：**产地/矿口 + 颜色 + 种水 + 珠形 + 尺寸/颗数/克重 + 品类词**，例如“南紅手串 涼山瓦西錦紅老型珠1串單珠約8.5至8.6mm”。
- 颜色是第一卖点：柿子紅（53）、錦紅（52），其次是櫻桃紅、牛血紅/血錦、玫瑰紅、火焰紅、冰紅、朱砂點。行家常说的排序是牛血红/锦红 > 柿子红 > 玫瑰红 > 樱桃红 > 冰飘（中新网报道把锦红列为最好，柿子红是锦红中的名贵品种）。“滿色滿肉”是固定搭配。
- 种水：“冰飄”出现最多（58），它既是种水也是一个独立品类（冰底飘红花，与满色料是两条价格线）。“荔枝凍”“高冰”“玉質感”属于质地描述。
- 产地/矿口词很密：保山 77、涼山 52、瓦西 46、川料 44，另有九口、聯合礦、楊柳、官坡、美姑、大山包、甘南紅；非洲南紅（非紅）是低价替代品，会明确标出。
- 处理：“天然”104、“原礦”33；“無注膠/無優化/無膠”9；有卖家主动披露“少量輕微充填”，也有写“A貨”的。
- 珠形“老型/老型珠”49 是南红特有的高频词（指仿老珠的鼓形/腰鼓形工），“直切”12、“手工珠”15。
- 尺寸写法：“卡10mm”“卡8mm”（卡尺量最小径）、“8.5至8.6mm”区间、“0.66公分”、“1.6*1cm”（算盘珠）；**克重是南红一物一拍的标配**。

### 1.5 SPU 建法总结（南红）

1. **一物一拍（单件单页，库存 1）**：占比最高，详情页样本里约 45%（14/31）；从标题看，约 58 条（19%）写了克重，46 条写了“瓦西”等具体矿口，“可議價｜XXmm 錦紅老型｜日期”这类给每条串起名字的格式也很常见。一页只放一条串，标题写**矿口 + 颜色 + 珠形 + 精确尺寸（卡XXmm，或“8.5至8.6mm”这样的区间）+ 克重 + 颗数**，描述写瑕疵（冰裂、砂眼、“少量輕微充填”），配图是这一条的实拍，常附视频或证书。没有 SKU。
2. **标准品多规格（按珠径分 SKU）**：一页一个款，SKU = 珠径（4–7 档，最多 14 档），常顺带写圈数或颗数；品级作为后缀，或者用另一个页面区分；每档库存 10–300。价格随珠径单调上涨，108 颗长串的价差远大于单圈。主要是“柿子紅/錦紅 保山/川料 + 磨砂/滿肉”这类统货。
3. **“编号 SKU”的伪一物一拍**：一页挂多条不同的实物，SKU 值就是图片编号（1–16）或给每条起的名字，每个 SKU 库存 1。本质还是一物一拍，只是借多规格的结构批量上架（见 101597674034）。

另有一种“**系列编号上架**”：同一卖家用“C87/C88/C89/C91 保山南紅手鍊…規格大約6mm/7.8mm/8mm/10mm”或“A1/A2”分开上架，每个编号一个页面，标题模板一样，只改尺寸和克重。

### 2.5 SPU 建法总结（小叶紫檀）

1. **标准品多规格（主流）**：一页 = 一种“料档 + 珠形”，SKU = 珠径×颗数（4–8 档）× 款式/配饰（可选）。价格主要由珠径决定：108 颗从 6mm 到 12mm 约 ×2–7；单圈 12mm→20mm 约 ×1.5。紫檀是木头，可以批量车珠，所以**标准品比例明显比南红高**。
2. **一物一拍（高端老料）**：标题写**规格数（1.0/1.5/2.0）+ 颗数 + 克重 + 纹理（金星/水波/瘤疤/魚鱗底/牛毛紋）+ 料性（老料/泥料/琴料/二膘）+ 工艺承诺（無膠研磨、未上油打蠟）**，价格常过万。按“规格+编号”一个页面一件。
3. **款式型 SKU（大众礼品款）**：底珠一样，SKU 是生肖、本命佛、貔貅等配饰款，价格只随尺寸变，配饰款基本不加价，大量依赖寓意词（我们不能照搬）。

### 3.5 SPU 建法总结（星月菩提）

1. **标准品多规格（主流）**：一页 = 一种料（海南/元寶籽/毛感料），SKU = 品级 × 珠形 × AxB 尺寸，常见 108 颗；库存几十到几百。最适合直接搬到我们的“标准品”模型。
2. **一物一拍 / 一物一图（老星月、开片、玩透、陈籽）**：一页一串，卖点是**年份（2019年的籽、98年老料、陳籽）、盘玩状态（玩透、開片、包漿、雞油黃）、颗数是否足数（現存102顆、104顆）**，价格很分散（700–100,000+）。
3. **设计款 / 配饰款**：单圈“繞指柔”或多圈手串，素珠很便宜，SKU 按配饰（天珠、瑪瑙、紫檀、綠松）和男女款（用尺寸区分）分，价格差约 20–60%。

## 4. 三个品种的共性、差异，以及和水晶类可能的不同

### 4.1 共性
1. **标题骨架一样**：`[产地/矿口] + [核心品质词] + [珠形] + [尺寸] + [颗数] + [品类词：手串/手鍊/佛珠/念珠] + [人群：男女款/女款] + [场景：文玩/盤玩]`。尺寸几乎都写进标题（南红 156/313、紫檀 87/183、星月 88/220 条带 mm/cm/珠径）。
2. **SKU 的第一维度都是“珠径（+颗数）”**，价格随珠径单调上涨，大尺寸段涨得更快。南红单圈 8→20mm 约 ×3.7，保山 6→22mm 约 ×10；紫檀 108 颗 6→12mm 约 ×2–7；星月 8x6→12x8 约 ×3–5。
3. **108 颗与单圈是两条线**：108 颗（多圈/项链两用/脖挂）对应小珠径（4–10mm）；单圈对应大珠径（8–22mm），颗数随珠径变（12mm 17 颗、15mm 15 颗、18mm 13 颗、20mm 12 颗）。颗数应该由“珠径 + 手围”推出来，而不是一个独立选项。
4. **品级很少成为独立维度**：南红、紫檀的品级都作为后缀拼进 SKU 值（“成色好”“畢業收藏級”“滿肉滿色少紋裂”“包漿老料滿金星款”）。只有星月出现了“玩家/畢業/珍藏”这样的品级档位。
5. **一物一拍很普遍**，而且有三种做法：①单件单页（库存 1，无规格，标题写精确尺寸和克重）；②一页多件，用编号或名字做 SKU，每个库存 1（“南紅:1–16”“珠玉在前1/2…108顆 實發”）；③同一模板按编号分开上架（C87/C88、A1/A2、NJ114、1.0 手珠手釧C）。
6. **规格名普遍被挪用**：Yahoo 默认的规格名是“顏色/顏色分類/純度/規格/尺寸”，商家把尺寸、颗数、款式全塞进“顏色分類”。说明商家需要的是**自由组合的“款式”字段**，平台预设的属性不够用。
7. **信任词**：天然、原礦、無注膠/無優化（南红）；無膠研磨、無油無蠟（紫檀）；乾磨、非水磨漂白、原生態無脫脂（星月）；保真、證書、一物一圖、實拍、所見即所得。

### 4.3 和水晶类可能的不同（推测，水晶部分没有在本次抓取，需由水晶组核对）
1. **品质轴不同**：水晶靠“净度/通透（冰透、无棉）+ 颜色饱和 + 包裹体（发晶、幽灵）”；文玩靠“料性 + 产地矿口 + 老/新 + 盘玩状态”。文玩会出现**时间维度**（年份籽、老料、包浆、玩透），水晶基本没有。
2. **尺寸表达不同**：星月用“直径×高”，紫檀用“1.0/2.0”这种 cm 规格，南红用“卡 X mm”。如果把尺寸字段统一成单一 mm，会丢信息，需要支持**珠形 + 两个尺寸**。
3. **颗数逻辑**：文玩有“108 颗”这类宗教计数（另有 18 子、36、54、114、120、216），它是独立的商品形态，不是手围推出来的。水晶多按手围定颗数。
4. **克重是文玩一物一拍的关键定价参数**（南红、紫檀尤其如此），水晶很少写克重。
5. **一物一拍比例**：文玩明显比水晶高，SKU 模型必须支持“单件库存 = 1 + 实拍图绑在 SKU 上”。
6. **合规风险**：水晶的风险是“能量/疗愈/招财”这类功效词；文玩的风险更多是**宗教用语**（開光、加持、本命佛、六字真言、修行）和寓意（貔貅招财、转运、辟邪）。还有描述里的养生功效话术，比如“戴玉七大功效”，过滤词表要覆盖这两类。

### 4.4 对我们建 SPU/SKU 的建议（供参考）
- SPU 至少分两类：**标准品**（料档 + 珠形固定，SKU = 珠径 × 颗数/圈数 × 可选品级）和**单品**（库存 1，属性直接写在商品上：精确尺寸区间、克重、颗数、瑕疵说明、实拍图或视频）。另外支持“一页多件”，SKU 用编号表示、每个库存 1，这样就不用拆成很多页面。
- 结构化属性建议：品种 / 产地·矿口·籽种 / 颜色（品种内的枚举）/ 种水或料性 / 纹理 / 珠形（圆珠、老型、桶珠、苹果圆、直切、算盘珠、药片）/ 尺寸（主径 + 可选副径）/ 颗数 / 圈数 / 克重 / 处理声明（天然无优化、注胶、充填、脱脂）/ 新旧状态（全新、陈籽年份、已盘玩）。
- 卖点词的“颜色、种水、纹理”需要**按品种定义各自的词表**，不能共用一套。
